# Technical Ownership Card — correção do M0a.1 Bun/Arch

- **Escopo e estado:** Engineering Cockpit M0a.1; execução local em Debian. Host Arch e CLI MSB real continuam `NOT_VERIFIED`. Nenhum comando MSB foi executado; nenhuma VM, sessão ou credencial foi alterada; M0b, push e deploy não iniciados.
- **O que mudou:** pin exato 1.4.4 preservado em `.bun-version`, `package.json` e `bun.lock`; o host que reportou 1.4.2 deve atualizar explicitamente o runtime via instalador oficial antes do bootstrap. `scripts/cockpit` requer o `bun` do PATH, valida a versão antes de qualquer operação e executa bootstrap frozen/sem scripts. Metadados runtime de npm removidos. Cache e diretório temporário do Bun ficam em `.cache/`; launcher é executável (`0755`).
- **Fluxo:** wrapper fixa a raiz (`scripts/cockpit:3`), resolve Bun do PATH e recusa ausência/mismatch (`scripts/cockpit:6-17`), fixa cache/tmp em projeto e delega bootstrap/start/verify/host-check ao Bun (`scripts/cockpit:18-31`). Runtime e entrada repetem a validação/guard; no modo host, um único `msb list` sem shell é limitado por timeout/bytes e persiste snapshot SQLite validado.
- **Risco e limite:** Bun 1.4.4 é requisito estrito, não fallback; Bun 1.4.2 será recusado até a atualização do Arch. O CLI real e formato da saída ainda não foram validados. `BUN_TMPDIR` não remove necessidade de rede no primeiro download do lock; com cache aquecido, `--offline` é suportado.
